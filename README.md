# Slides app

Slide shows rendered from markdown files served in the browser.

## Local development

```bash
yarn
yarn start
```

## Production build

```bash
yarn
yarn build
```

## Adding slides

- Add a folder with a URL safe name, in `src/slides`
- In the folder, use double digits to denote slides and their order, e.g., `01.md`, `02.md`, etc.
