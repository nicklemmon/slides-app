title: Type guards
description: Functions that prevent runtime type errors
---

How do we safely handle arbitrary user entry? The parameter is right now so we're good.

```ts
type ReferralSource = "facebook" | "reddit" | "google";

// The user has a valid value in the URL
const params = "?referral_source=google";
const referral_source = new URLSearchParams(params).get("referral_source");

// And we save it to a database somewhere ✅
await saveReferralSource(referral_source);
```
