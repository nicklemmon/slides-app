## Trust me, bro

Telling TypeScript you promise the types are right is _not_ safe.

### Type-casting (using `as`)

```ts
function getPerson() {
  const res = await fetch("/api/person/12345");

  // Trust me, bro
  const person_json = (await res.json()) as Person;

  return person_json;
}
```

### Using generics (for example, the Angular `http` service)

```ts
@Component({
  selector: "app-person-route",
  templateUrl: "./app-person-route.component.html",
  styleUrls: ["./app-person-route.component.css"],
})
export class AppPersonRouteComponent {
  getPerson() {
    // Trust me, bro
    return this.http.get<Person>();
  }
}
```
