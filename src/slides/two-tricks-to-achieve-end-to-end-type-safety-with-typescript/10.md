Let's make an API call!

The bad way (but the most common way you will see out there in the wild):

```ts
type Person = {
  name: string;
  age: number;
  birth_place?: string;
  eyes: {
    color: string;
    size: "sm" | "md" | "lg";
  };
};

function getPerson() {
  const res = await fetch("/api/person/12345");

  // Trust me, bro
  const person_json = (await res.json()) as Person;

  return person_json;
}
```
