---
title: Type guards
description: Functions that prevent runtime type errors
---

How do we safely handle arbitrary user entry? Uh oh, `"potato"` can't be right.

```ts
type ReferralSource = "facebook" | "reddit" | "google";

// The user has an invalid value in the URL 😥
const params = "?referral_source=potato";
const referral_source = new URLSearchParams(params).get("referral_source");

// And we save it to a database somewhere - but the backend will throw an error ❌
await saveReferralSource(referral_source);
```
